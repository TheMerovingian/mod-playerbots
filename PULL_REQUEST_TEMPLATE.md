# Pull Request Template

Use this template for every pull request in this repository.

## PR Title

A short, succinct summary of the largest aspect of what was changed
(e.g. `feat(gather): zone-routed resource gathering behaviour`).

## Changes Implemented

Outline the changes that were implemented in this repository.

## Fixes Required

Summarise what fixes were required during testing and validation. If no
fixes were required, state so explicitly (e.g. "No fixes were required
during testing — all changes validated as submitted.").

## Validation & Results

Report the validation that was performed (build, runtime, live-server
tests) and a summary of the results.

## Dependencies

Note whether the changes depend on code included in another module or in
the AzerothCore server/core code. If there are no dependencies, state so
explicitly (e.g. "No dependencies — this repository's changes are
self-contained.").
